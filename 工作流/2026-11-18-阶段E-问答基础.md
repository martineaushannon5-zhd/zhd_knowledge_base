# 阶段 E 基础：带引用问答引擎与适配器契约 — 验证报告

日期：2026-11-18。范围：知识库 AI 的**离线基础**。用户尚未确认模型提供商与内容外发授权，因此本阶段不接真实模型、不发任何网络请求，先把"检索→带引用回答→无依据拒答"的引擎、适配器契约、引用完整性与防注入做扎实，并用离线适配器跑通 UI。

## 交付

- electron/ai/qa.cjs：问答引擎 ask(vault, query, adapter)。**拒答与引用校验在引擎侧**，不交给适配器——适配器或笔记里的注入指令都绕不过。
  - 空查询/无检索命中 → refused, reason=no-basis。
  - 检索用 vault.search（已排除 secret 与 trashed）；上下文再过滤 secret。
  - 引用完整性：只保留真实检索到的笔记 id，剔除幻觉引用与重复。
- electron/ai/adapter.cjs：适配器契约 { name, generate({query,context})→{text,citations} }。
  - OfflineExtractiveAdapter：离线、零网络、提取式摘要（非生成），明确标注"未连接生成模型"。
  - createCloudAdapter：占位，未授权调用即拒绝；真实实现待授权后做，当前不接线、无网络。
- IPC kb:ask（默认离线适配器）+ preload kbStore.ask + data.ts askKnowledge（浏览器回退为本地提取式）。
- UI：顶栏"问知识库"面板，输入提问→显示带引用的回答/拒答，引用芯片可点击打开对应笔记；明确标注离线、不发送内容到云端。

## 验证（真实运行）

- tests/qa.test.ts 7/7：无依据拒答（空/无命中）、离线带引用回答、剔除幻觉引用、防注入（笔记内"忽略规则/引用 fake-id"被引擎拒绝，无依据拒答不受影响）、secret 排除、云适配器未授权拒绝、空文本回退仍校验引用。
- tests/interface.cjs 新增问答组通过：离线带引用回答、引用打开笔记、无依据拒答、标注不外发；共 10 组全过。
- 回归：login 8、vault 14、storage 46 全过；npm run build 通过。

## 安全边界（已落实）

- 默认离线适配器，零网络；云适配器未授权即拒绝，未接线。
- 笔记内容视为不可信数据：引擎的拒答/引用校验不受适配器或笔记内指令影响。
- secret 敏感笔记不进检索结果与上下文。
- 不回显秘密；UI 明示"不发送内容到云端"。

## 未完成 / 需用户决策

- **真实生成模型未接**：当前是提取式检索摘要，不是模型生成。接真实模型需用户先确认：① 提供商（本地 Ollama / 云 API / 混合）② 是否允许把检索到的笔记内容外发。未确认前保持离线。
- 引用高亮定位到片段、流式输出、对话历史、多轮追问后置。
- 云适配器实现需配合秘密引用读取授权与内容外发授权。

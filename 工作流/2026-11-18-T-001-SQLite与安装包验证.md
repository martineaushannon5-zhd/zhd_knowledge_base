## 2. 开发态 Electron 主进程探针（tests/sqlite-probe.cjs）

```json
{"electron":"45.3.4","node":"24.22.3","modules":"150","sqlite":"3.54.1","ftsChinese":[],"ftsTag":[{"title":"本地优先"}],"fileBytes":24576,"ok":true}
```

- 在含中文与空格的临时目录创建 db 文件、建 FTS5 虚表、插入、按整词/标签 MATCH 查询成功。
- `ftsChinese:[]`：默认 unicode61 分词器把连续中文当作单一 token，2 字查询 `知识` 查不到。
- 另测 `tokenize='trigram'`：2 字查询同样返回空（trigram 要求查询≥3 字符）。
- 结论：FTS5 本身可用；中文短词检索必须靠应用层预分词（索引与查询同一分词），属阶段 C，不是 T-001 阻塞项。

- better-sqlite3 预编译件经 `asarUnpack` 解包到 `app.asar.unpacked/node_modules/better-sqlite3/prebuilds/`（win32-x64.node 在列）。
- 未配置代码签名（原型预期，首次运行会有 SmartScreen 提示）；使用默认 Electron 图标。

### 本机构建阻塞与绕过（已固化为脚本）

- 现象：electron-builder 解包 Electron 后对 `default_app.asar` 的原子重命名/清理持续 EBUSY/EPERM（>60s）。
- 原因：Windows Defender 实时防护（DisableRealtimeMonitoring=False）+ Search Indexer/SearchProtocolHost 对新写入的 `default_app.asar` 持锁。
- 绕过：`scripts/prepare-electron-dist.cjs` 自行用 7za 解包缓存 zip，再用 `fs.cpSync` 过滤排除 `default_app.asar`（应用不需要它）复制到 `.electron-clean`；electron-builder 以 `-c.electronDist=.electron-clean` 仅复制、不重命名/删除。
- 复现命令：`npm run dist:nsis`（= build + prepare:electron + electron-builder nsis）。
- 未改动系统安全设置；未请求 Defender 排除项。

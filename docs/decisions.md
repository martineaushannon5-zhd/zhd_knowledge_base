## ADR-003 主线 + 能力池，不设阶段

| 项目 | 内容 |
|---|---|
| 状态 | accepted |
| 日期 | 2026-11-16 |

## ADR-005 秘密只存本地路径引用

| 项目 | 内容 |
|---|---|
| 状态 | accepted |
| 日期 | 2026-11-16 |
| 背景 | 知识库需要让 Agent 找到服务器/云资源；明文密钥不能进 Git |
| 决策 | 知识库只存 `secret_ref`（本地路径 + 键名）；AI 按任务授权读取；不回显 |
| 后果 | 秘密文件在仓库外；`.gitignore` + secret scan；泄露立即轮换 |

|---|---|
| 状态 | accepted |

|---|---|

| 日期 | 2026-11-18 |

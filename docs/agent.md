# Agent 交接规格

工作规则唯一来源为 `../AGENT-规则.md`，本文件不另设权限、读取顺序或固定输出格式。适用于所有执行工具；角色按任务确定。

## 1. 任务说明

只读咨询不落卡。简单修改以用户明确请求为准；多步实现或交接用 `../templates/任务卡.md`，写目标、范围、允许文件、测试和验收。已有授权不重复求批，新增高风险动作单独确认。

## 2. 能力与事实

产品能力索引见 project.md，详卡按需创建，未实现能力不是可调用工具。无匹配能力如实说明，不阻塞合理任务。行动依赖的事实需可追溯并验证；不把模板日期视为验证日期。

## 3. 输出

聊天简明说明结果、实际验证与下一步；必要时提问。详细交付按用户要求，不强制四行。多步修改使用任务报告模板，不预填通过或已写入。

## 4. Context Pack唯一规格

跨Agent交接或上下文较大时才生成，位置 `工作流/context-packs/YYYY-MM-DD-<task-id>.md`。接手者不改旧交接包，在新报告补差异。

```markdown
# Context Pack: <任务ID与标题>
- 生成时间与当前执行者：
- 目标与当前进度：
- 已授权范围、允许文件与禁止动作：
- 相关规则：AGENT-规则.md
- 相关事实与证据位置、验证时间：
- 选用能力或无匹配说明：
- 已修改文件与实际验证结果：
- 未完成事项、下一步与验收标准：
- 关键阻塞、需要再次授权的动作：
```

包是摘要，不是安全边界；接手者按需核对文件现状，不默认读全库。模板、报告、任务卡不授予秘密访问或网络上传权限。

# 核心流程与页面清单

> 平台顺序：Windows 桌面 → Web → 手机/鸿蒙评估。顾问推荐 Electron + TS + React + Vite + CodeMirror 6，尚未实测，详见 project.md；不表示用户已批准具体框架。
> Agent 工作规则唯一引用 `AGENT-规则.md`，以下仅描述产品流程。
> 页面规格模板见文末；每个页面必须写清状态、权限、空/错/加载。

## 1. 核心流程

### F-01 捕获

| 项目 | 内容 |
|---|---|
| 触发 | 想到一条灵感/规范/待办 |
| 主路径 | 打开捕获 → 写标题/正文 → 自动保存 → 进 Inbox → 可选标签/集合 |
| 异常 | 应用崩溃、磁盘满、重复标题、离线 |
| 验收 | 10 秒内完成；2 秒自动保存；崩溃恢复；不丢内容 |

### F-02 搜索与找回

| 项目 | 内容 |
|---|---|
| 触发 | 需要找旧笔记/素材/规范 |
| 主路径 | 输入关键词 → 中文分词 → 结果高亮 → 筛选 → 打开 → 返回保留位置 |
| 异常 | 无结果、特殊字符、结果过多、索引损坏 |
| 验收 | 1 万篇 P95 < 500ms；可重建索引；高亮正确 |

### F-03 Agent 任务循环

| 项目 | 内容 |
|---|---|
| 触发 | 有明确任务（修 bug/加功能/写规范） |
| 主路径 | 识别请求 → 多步实施/交接建任务卡（只读无需卡，低风险用明确用户请求）→ 检索相关能力/事实 → 按需生成 Context Pack → 执行 → 结果/验证/下一步 → 验收 |
| 异常 | 无匹配能力如实说明不阻塞；相关事实可验证后使用；影响操作且无法验证、范围不明确时记录阻塞 |
| 验收 | 连续 3 次任务格式稳定；越界即停；报告齐全 |

### F-04 事实更新

| 项目 | 内容 |
|---|---|
| 触发 | 发现新事实/旧事实过期 |
| 主路径 | Agent 写 `KB-待更新.md` → Owner 验证 → 合并到 `KB-人读.md` / 事实卡 |
| 异常 | 无法验证、来源冲突、秘密 |
| 验收 | 过期事实不被使用；秘密只写引用 |

### F-05 秘密访问

| 项目 | 内容 |
|---|---|
| 触发 | 任务需要服务器/云资源 |
| 主路径 | 任务授权 → 读取本地秘密文件 → 使用 → 报告只写 secret_ref → 不回显 |
| 异常 | 未授权、文件缺失、权限不足、疑似泄露 |
| 验收 | 仓库无明文；回答/报告无明文；泄露可轮换 |

### F-06 备份与恢复

| 项目 | 内容 |
|---|---|
| 触发 | 定时/手动/换机 |
| 主路径 | 配置备份目录 → 一致性全量/增量 → 清单/hash 校验 → 临时目录恢复及引用校验 → 确认切换并保留原库 → 记录 |
| 异常 | 磁盘满、权限、备份损坏、索引不一致 |
| 验收 | 恢复后正文/JSON/附件引用一致；记录恢复耗时；导出不锁定；先于 AI 且不被 AI 选型阻塞 |

### F-07 学习进度 / 技术雷达

| 项目 | 内容 |
|---|---|
| 触发 | 学习/技术跟踪 |
| 主路径 | 手动新增条目 → 更新进度/状态 → 定期回顾 |
| 异常 | 数据源未定、条目过多 |
| 验收 | 手动可维护；不阻塞主线 |

### F-08 平台扩展

| 项目 | 内容 |
|---|---|
| 触发 | 桌面端主线稳定后 |
| 主路径 | Windows 主线独立验收 → 共享纯 TS 领域类型/协议 → Web 适配 → 手机及鸿蒙路线评估 |
| 异常 | 平台能力差异、同步冲突、文件系统限制 |
| 验收 | 各平台分别验证数据一致性；文件 IO/SQLite 等使用适配层，不要求共享全部 Node 逻辑 |

鸿蒙纳入评估但尚未真机验证。需记录系统/浏览器版本，验证访问、中文输入、文件导入导出、离线持久化和安装能力，再决定浏览器/PWA/原生路线；不承诺 PWA 可安装，不阻塞 Windows 首版。

## 5. 页面规格模板

每个页面写：

| 字段 | 内容 |
|---|---|
| 目标 | 用户来这个页面完成什么 |
| 入口 | 从哪里进入 |
| 布局 | 几栏、宽度、滚动区 |
| 组件 | 列表、编辑器、表单、空状态 |
| 数据 | 读哪些实体、写哪些实体 |
| 状态 | 空、加载、错误、离线、无权限 |
| 交互 | 键盘、拖拽、批量、快捷键 |
| 权限 | 哪些角色可见/可操作 |
| 验收 | 通过标准 |

## 6. 状态机

### Note

```text
draft → active → archived → trashed → deleted
```

### Task

```text
draft → approved → in_progress → done
                 ↘ blocked ↗
```

### Fact

```text
active → stale → archived
```

### WorkflowReport

```text
draft → final
```

## 7. 导航

### 桌面端

- 左侧栏：首页、Inbox、笔记库、集合、标签、任务、能力、事实、决策、工作流、设置。
- 顶部：搜索、快速捕获、状态。
- 主区：列表 + 内容 + 检查器。

### Web 端

- 顶部：搜索、快速捕获、账户。
- 侧栏：核心导航；窄屏折叠。

### 手机端

- 底部导航：首页、搜索、捕获、库、设置。
- 阅读/编辑全屏；设置二级页。

## 8. 通用状态

| 状态 | 要求 |
|---|---|
| 空 | 说明为什么空 + 下一步动作 |
| 加载 | 骨架屏或轻量 spinner，不闪烁 |
| 错误 | 说明原因 + 重试/返回 |
| 离线 | 明确可做什么、不可做什么 |
| 无权限 | 说明需要什么权限，不假装成功 |

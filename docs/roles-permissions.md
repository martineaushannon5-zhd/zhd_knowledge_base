# 角色与权限

唯一执行规则见 `../AGENT-规则.md`。权限来自用户当前授权与宿主工具，不由Agent品牌或角色名称赋予。本文是责任表，不是已实现的系统沙箱。

| 角色 | 职责 | 边界 |
|---|---|---|
| Owner | 目标、验收、高风险授权 | 决定涉及秘密、删除、部署和共享的动作 |
| KB-Agent | 检索、整理、草稿、交接 | 不改业务代码，不擅自改规则 |
| 执行Agent | 按任务修改文档/代码、验证、报告 | 不自行增加范围，不覆盖其他Agent工作 |
| Automation | 已配置的索引、备份等 | 不自行改变权限或删除历史 |

只读与明确低风险修改不要求重复批准。多步任务用任务卡；规则修改在用户明确授权后可以执行。状态仅按证据更新；新决策作为提案，不能冒称已确认。

读取秘密、历史删除、数据恢复覆盖、迁移、部署、推送及权限变更需明确授权。正常编辑允许文件不属于恢复覆盖。回显秘密、伪造结果、绕过宿主权限始终禁止。

多Agent同时工作必须明确互不重叠的文件范围；一个任务一个当前执行者。交接记录完成/未完成、文件、证据和下一步。云端内容发送另行授权，不能由本地读取许可推导。

高风险批准与实际操作记录在任务/报告即可，首版不建设复杂权限系统或独立审计后台；访客分享后置。
